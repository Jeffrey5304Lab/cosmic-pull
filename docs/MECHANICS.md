# Star Sort 機制庫與反重複框架（Fable 5，2026-08-15）

> `REBOOT-PLAN.md` 的姊妹篇。回答一個關鍵問題：**原設計為什麼重複？新設計
> 拿什麼保證幾百關不膩？** 答案全部參考自熱門遊戲的已驗證機制（copy till
> you make it），並標明每個機制「參考自誰、改變哪個決策維度」。

---

## 1. 先診斷：原設計為什麼「無腦 + 重複」

回看 36 個拔栓關卡，它們其實只有**一個決策維度**：「先拔哪根」（順序）。
所有「變化」都是佈局變化——同一條規則換位置擺。玩家第 5 關就摸透規則，
之後 31 關都在重複同一種思考（或根本不思考，亂試）。

**反重複的本質不是「更多關卡」，是「更多決策維度」。**
熱門長青解謎遊戲的共同結構：

- **規則層**：4–6 個正交的決策維度，各由一個機制承載
- **節奏層**：每 20–30 關才引入一個新機制（Royal Match 的紀律：一次教一個、
  用關卡設計教學而非文字）
- **組合層**：中後期把已學機制兩兩疊加——N 個機制 = N² 種組合關型
- **參數層**：同機制內用數值曲線（顏色數/瓶數/空瓶數/最少步數）拉出深淺

原設計四層全缺。新設計把這個結構當骨架。

## 2. 決策維度 × 機制庫（全部有市場出處）

每個機制入庫的門檻：**必須新增一個決策維度，不能只是新皮膚。**

### 維度 A：順序（基礎規則自帶）
「先倒哪一瓶、把哪個空瓶留給誰」——sort 品類的核心深度來源。
- **參考**：所有 Water/Ball Sort。NP-complete 的來源就在這裡。
- **深度旋鈕**：顏色數 C、瓶數 N、空瓶數 E、solver 最少步數 M。
  專家級配置可到 14+ 瓶（品類實證）。
- **一個重要變體選擇**：Water Sort 一次倒「連續同色整段」，Ball Sort 一次
  只移一顆。**分支因子不同 = 難度手感不同。** 我們採 Water 規則為主
  （傾瀉演出更爽），但保留「一顆一顆」當後期變體瓶（見彗星瓶）。

### 維度 B：資訊（不完全資訊 → 記憶與推理）
- **星雲瓶**（參考：Mystery/Hidden bottles，Water Sort Magic Puzzle 等）：
  瓶內被星雲遮蔽，只有頂層可見；倒出才揭曉下一層。把「規劃」變成
  「推理 + 風險管理」，是品類公認把難度拉最高的機制。
- **深空瓶**（參考：Ball Sort 的 opaque tube）：整瓶不可見，只記得自己
  倒進去什麼——純記憶負擔，作為星雲瓶的重型版，罕用。

### 維度 C：依賴（目標排序 → 多步規劃）
- **黑洞封印瓶**（參考：Covered/Locked bottles）：被封印，直到你集滿某個
  指定顏色才解封。強制玩家規劃「先完成誰」——正是原設計 L25 閘門
  好玩的原因，這裡用確定性規則重生。
- **連鎖封印**（自然延伸）：解封 A 才能解封 B——依賴鏈。

### 維度 D：資源（預算管理）
- **彗星瓶**（參考：one-way / pour-out-only bottles）：只能倒出不能倒入
  ——等於「會耗盡的資源」。
- **冰凍瓶**（參考：Frozen bottles）：可以倒入但不能倒出——倒進去的
  決定是不可逆的，落子無悔。
- **限步挑戰**（參考：limited-moves 模式 + 我們的 solver）：Boss 關給
  M×1.1 的步數上限。因為有 solver，這個上限是**誠實的**，不是拍腦袋。
- **窄瓶/巨瓶**（參考：tube-size variation）：容量 2 或 6 的瓶子改變
  空間預算的形狀。

### 維度 E：正向驚喜（節奏調劑，不是難度）
- **超新星層**（參考：wildcard）：百搭色，接觸任何色都算同色——
  幫玩家解圍的糖，困難段落的減壓閥。
- **雙倍星塵瓶**：理好整瓶 ✦ 加倍——接經濟系統。

### 明確不做的（有量測依據）
- **計時/移動危險物**：本專案已證明（timing sweep：t≈0 即獲勝時機，
  玩家無法瞄準）；且 zen 品類鐵律是無時間壓力。
- **物理結果**：模糊性毀掉推理感，全案退役。
- **Hexa Sort 的盤面放置維度**：好機制但等於另一個遊戲，若做是 P3 的
  獨立模式，不混入主線。
- **Screw Jam 的空間遮擋**：需要 3D 分層視覺，與手繪紙風衝突，捨棄——
  它的「依賴」維度已由黑洞封印瓶承載。

## 3. 登場節奏表（cadence，抄 Royal Match 的紀律）

| 關卡帶 | 內容 | 決策維度 |
|---|---|---|
| 1–5 | 純教學（3 色、寬鬆），**無腦，刻意的**（使用者指定） | A |
| 6–25 | 基礎規則爬坡：C 4→7、E 3→2 | A |
| **26** | ✦ **星雲瓶登場**（單獨教學關 → 3 關練習） | +B |
| 27–50 | 基礎 × 星雲輪換；C 至 8 | A,B |
| **51** | ✦ **黑洞封印瓶登場** | +C |
| **76** | ✦ **彗星瓶/冰凍瓶登場** | +D |
| **101** | ✦ **超新星登場**（獎勵型） | +E |
| **126** | 窄瓶/巨瓶 | D′ |
| 150+ | **組合關**：星雲×封印、彗星×限步…（N² 空間） | 疊加 |
| 每 25 關 | **Boss 關**：limited-move（solver 門檻）＋星座章節結算 | 高潮 |
| 每日 | 固定 seed 每日一題，輪換一個 modifier | 回訪 |

生成器都吃同一套參數 `(C, N, E, M, variants[])`，所以每一帶都是
**無限供給**，手工只調曲線。

## 4. Solver 相容性（每個機制都要能被證明）

這是我們相對整個品類的技術優勢，每個機制入庫前必須過這關：

| 機制 | solver 處理 | 可證明性 |
|---|---|---|
| 基礎排序 | BFS/A*（colour-break heuristic） | ✅ 最少步數精確 |
| 星雲瓶 | 生成時全知求解（保證可解）；玩家視角另算「揭示風險」指標 | ✅ |
| 黑洞封印 | 狀態機加一個 flag，搜尋空間不變質 | ✅ |
| 彗星/冰凍 | 合法步過濾器 | ✅ |
| 限步 | 直接用 M 定門檻 | ✅ 誠實難度 |
| 超新星 | 等價類展開 | ✅ |

全部是整數邏輯——**跨平台 100% 確定性**，物理時代的浮點脆弱性不存在。
CI 守則：每關（含生成關的抽樣）必須 solver 可解；難度帶的 M 分布單調；
每個變體瓶有專屬單元測試。

---

## 5. 這套如何直接回應兩個原罪

**「無腦破關」** → 深度來自 NP-complete 的順序維度 + solver 分級保證
每一帶的最少步數下限。亂試在 10 瓶 8 色下是天文數字的排列，
**試錯第一次比思考慢**——這是結構保證，不是關卡設計師的祈禱。

**「重複的邏輯」** → 五個正交決策維度輪換 + 每 25 關一個新規則 +
150 關後的組合矩陣。玩家每隔一段時間就要**更新自己的策略模型**，
這正是 Hexa Sort／Royal Match 們留住人幾百關的結構性原因。
