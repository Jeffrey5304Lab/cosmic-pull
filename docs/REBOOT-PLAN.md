# Cosmic Pull → Star Sort 大重改計畫（Fable 5，2026-08-15）

> 使用者拍板：不受 Cosmic 原設計束縛，要「主題有趣、邏輯清晰、有難度需要解謎」，
> 可以模仿熱門遊戲（copy till you make it）。本文件是完整重開計畫。

---

## 1. 為什麼必須換核心循環（證據，不是感覺）

三輪量測，結論一致：

| 量測 | 結果 |
|---|---|
| 規則習慣（拔平栓）通關 | 26/36 關第一次就贏 |
| 暴力亂拔（免費重試） | 25/36 關 3–5 次內矇過 |
| 用 L25 DNA 重建 14 關後 | 使用者仍然：「和預期差太多」 |

根本原因有三，全部是**「拔栓」動詞的結構性缺陷**，調關卡救不了：

1. **決策空間太小。** 2–5 根栓 = 幾種到幾十種排列。免費重試下，試錯永遠比思考快。
   唯一撐住的關卡（L25，亂拔 0%）需要 5 根栓＋閘門＋連鎖——而那個引擎的變化
   空間極窄（7 個變體試驗 7 個失敗）。做得出難度，做不出「多樣的難度」。
2. **物理模糊。** matter.js 的結果無法精確預測 → 玩家無法真正「推理」，
   只能「試試看」。解謎感的前提是**確定性**：我做這步，必然發生那件事。
3. **內容成本高。** 每一關都要手工幾何＋物理驗證＋防脆弱。36 關已是極限，
   競品是上千關。

**教訓：解謎感 = 確定性 × 大狀態空間 × 完全資訊。物理拔栓三者皆無。**

## 2. 新核心：「星塵分裝」(Star Sort)

**一句話：Water Sort 的邏輯核心，穿上我們已經做好的宇宙傾瀉外衣。**

規則（30 秒學會）：
- 畫面上有 N 個**試管瓶（星瓶）**，裝著分層的彩色星塵，另有 2 個空瓶。
- 點一個瓶再點另一個瓶：頂層星塵**傾瀉**過去——只有「目標瓶頂層同色或空瓶、
  且有空間」才允許。
- 把每種顏色各自集滿一整瓶 = 過關。無計時、無懲罰、**有 undo**。

### 為什麼是它（而不是螺絲、滑塊、或繼續拔栓）

| 判準 | Star Sort | 螺絲類 | 滑塊類 | 拔栓（現況） |
|---|---|---|---|---|
| 邏輯清晰（確定性） | ✅ 完全 | ✅ | ✅ | ❌ 物理模糊 |
| 真解謎深度 | ✅ **NP-complete**，高關卡需 3–5 步 lookahead | ⚠️ 中 | ⚠️ 中 | ❌ 已證淺 |
| 可證明的難度 | ✅ **A\*/BFS solver 可量測每關最少步數** | ⚠️ 難 | ✅ | ❌ 只能猜 |
| 無限內容 | ✅ 生成器＋solver 驗證 = 無上限關卡 | ⚠️ | ⚠️ | ❌ 手工 |
| 重用現有資產 | ✅ **~90%**（見 §6） | ❌ 要 3D 感 | ❌ | — |
| 市場驗證 | ✅ 品類多年霸榜、受眾巨大 | ✅ 但 2025 已擁擠 | ✅ 舊 | ❌ 已衰退 |
| 我們的量測/測試文化 | ✅ **完美契合**（solver 即測試） | ⚠️ | ⚠️ | 已建但受限 |

拔栓品類本身 2019 起飛後已衰退；sort 品類至今仍是下載榜常客。
我們吃過的虧（難度不可證明、內容做不動）正好是 sort 品類的天生強項。

> **機制細節與反重複框架**：見姊妹篇 **`docs/MECHANICS.md`** ——五個決策維度
> 的機制庫（各有市場出處）、每 25 關的登場節奏表、組合矩陣、solver 相容性。

### 差異化（不是純抄）

市場上千個 Water Sort 全是「玻璃試管 + 液體」。我們的版本：
1. **視覺**：手繪 ink-on-paper 星瓶，傾瀉的是發光星塵（P0 已做好的加法拖尾、
   傾瀉音、慢動作全部直接沿用）——市場上沒有這個質感。
2. **主題敘事**：每關的星塵理好後飛上夜空點亮星座（勝利動畫已做好）→
   「整理星空」的 meta 直接接上，比「排水」有故事。
3. **機制曲線**（皆為品類已驗證的變體，重新皮膚化為宇宙元素）：
   - **星雲瓶**（= hidden colours）：內容物被星雲遮住，倒出才揭曉 → 記憶+推理。
   - **黑洞封印瓶**（= locked）：集滿指定色才解鎖。
   - **彗星瓶**（= 只能倒出不能倒入）。
   - **超新星**（= wildcard 層，百搭色）。
   - 這些直接對應品類成熟變體（locked/frozen/encrypted bottles），
     是「copy till you make it」的安全抄法。

## 3. 難度設計 —— 這次是可證明的

核心武器：**BFS/A\* solver 進 CI**（品類標準做法）。每一關生成時：

1. **生成**：從「已解狀態」反向隨機倒 K 次（保證可解），或正向生成＋solver 驗證。
2. **量測**：solver 回報「最少步數 M、分支因子、死路密度」。
3. **分級**：難度 = f(顏色數 C、瓶數 N、空瓶數 E、M)。
   - 教學：C=3, E=2, M≤8（前 5 關，使用者要求的無腦教學區）
   - 普通：C=6–8, E=2, M 15–30
   - 困難 ✦：C=9–12, E=1–2, M 35+，或帶星雲瓶（不完全資訊）
4. **星等**：3★ = 步數 ≤ M×1.15；2★ ≤ M×1.5。**終於有真的精通追求**——
   solver 保證門檻誠實，不是拍腦袋。
5. rote/monkey/brute 全套量測退役，換成 **solver 套件**：可解性、步數分布、
   難度單調遞增曲線，全部自動驗證。物理脆弱性問題（跨平台浮點）整個消失——
   邏輯是整數運算，**永遠確定性**。

內容量問題同時解決：生成器 + 分級 = **無限關卡**，手工只需要調曲線和設計變體登場節奏。

## 4. UI/UX：從霸榜作品抄什麼（copy till you make it）

品類領導者（SortPuz、Water Sort Puzzle 等）共同的 UX 決策，全部照抄：

| 抄什麼 | 為什麼 |
|---|---|
| **點選→點倒**（tap-tap，非拖曳） | 單指、單手、零精度要求；選中瓶「浮起」示意 |
| **Undo 永遠在**（免費 3–5 次/關，看廣告補充） | 鼓勵實驗 = 解謎感的核心；也是品類最大廣告位 |
| **+1 空瓶 booster**（看廣告） | 第二大廣告位；卡關的儀式性出口 |
| **重來零成本、零載入** | 沙盒感 |
| 倒完自動高亮「可倒目標」新手期 | 教學不用文字 |
| 集滿一瓶：瓶身閃光+蓋章「✓」+ 小噴發 | 中途獎勵節拍（我們的 cupBurst 直接改造） |
| 關卡數大大地顯示「Level 137」 | 進度感 = 留存感 |
| 每 20–30 關出新變體瓶 | 打破單調的節奏器 |
| 失敗不存在（只有卡住→undo/重來/加瓶） | zen 品類鐵律，和我們 cozy 方向一致 |

**保留我們自己的**（差異化資產，不抄別人）：
紙上星光美術、傾瀉音/慢動作/星座勝利（P0 juice）、章節天空、✦ 經濟＋主題商店、
每日星塵、雙語、分享卡。**這些全是現成的。**

## 5. 玩法循環全圖

```
單局（60–180 秒）：
  看盤 → 規劃（哪個瓶先騰空？）→ 傾瀉（爽感演出）→ …
  → 集滿單瓶（小高潮）→ 全部理好 → 星塵飛天畫星座（大高潮）→ ✦ 結算

長線：
  無限關卡（生成） · 每 25 關解鎖新變體瓶 · 星座圖鑑一章章點亮
  · ✦ 買天空主題/瓶身樣式 · 每日星塵 · 每日一題（固定 seed 全球同題）
```

| i18n、privacy/UMP、AdMob、原生殼、icon | ✅ 原封沿用 |
| 測試文化/headless 截圖/playwright | ✅ 沿用（solver 取代物理測試）|
| 渲染器（紙、瓶、星塵粒子） | 🔄 改造：畫「星瓶」取代拔栓盤面 |

| 36 個拔栓關卡 | ❌ 退役（保留代碼于 git 歷史） |
| 拔栓 sim + rote/trap/stuck 測試 | ❌ 退役 |

估計：**~70% 的程式碼與 100% 的上架準備直接存活。** 重寫的只有
core loop（sort 邏輯 ~200 行、確定性、極好測）+ 盤面渲染 + 關卡生成器。

## 7. 分階段執行計畫

### P0 — 可玩核心（目標：一個週末的量）
| # | 項目 | 量 |
|---|---|---|
| 1 | `sort.ts` 核心邏輯（狀態、合法步、勝利判定、undo 棧）＋完整單元測試 | 小 |
| 2 | `solver.ts`（BFS＋colour-break heuristic）＋生成器（反向生成保證可解）＋難度分級 | 中 |
| 3 | 星瓶渲染（紙質瓶、分層星塵、tap-tap 選取浮起）＋傾瀉 tween 接既有音/粒子 | 中 |
| 4 | 30 關固定曲線（教學 5 無腦 → 漸進）＋星等（solver 門檻） | 小 |
| 5 | Undo、重來、＋1 瓶（先不接廣告） | 小 |

**P0 完成即可回答核心問題：「這下好玩了嗎？」——請真人（你）驗收後才繼續。**

### P1 — 完整遊戲（1–2 週）
6. 變體瓶：星雲（hidden）→ 黑洞（locked）→ 彗星（pour-only），每 25 關一個
7. 無限關卡模式＋「每日一題」（固定 seed）
8. meta 接回：星座點亮改為每 N 關一顆星；✦ 結算改為步數效率獎勵
9. 廣告位遷移：undo 補充＋加空瓶（比現在的位置高頻自然）
10. 選單/HUD 改版：大關卡數、章節進度條

### P2 — 打磨與擴張
11. 瓶身樣式商店（✦ sink 擴充）、成就
12. 週期活動關（特殊變體組合）
13. IAP（移除廣告/✦ 包/無限 undo）

### 保底方案（如果你想先低成本驗證）
P0-1+2（純邏輯＋solver）可以先配「開發用醜 UI」在兩三天內出原型；
手感對了再花渲染的工。**建議就這麼做。**

## 8. 風險與明說的取捨

- **「這不就是 Water Sort 換皮？」** 對，這正是策略（copy till you make it）。
  品類巨大、我們的皮（星空手繪+傾瀉 juice+星座 meta）是真差異化。原創性放在
  呈現層，不放在被驗證過一千次的規則層——之前反過來做，付了三輪學費。
- **傾瀉物理感消失？** 不會全消失：倒的動畫仍是粒子流（tween 驅動），爽感保留，
  只是**結果**不再由物理決定。確定性是解謎感的代價，也是它的來源。
- **既有 36 關作廢。** 是沉沒成本。量測已證明它們留不住你自己。
- 命名建議沿用「Cosmic Pull」→ 副標改（或改名「Star Sort / 星塵整理術」），
  上架資料只動文案。bundle id 未上架前仍可改。
